I'm a Computer Science student focused on **AI and machine learning**. I build Python APIs, document intelligence tools, and web applications, with an interest in making model outputs traceable to their sources.

My projects range from citation-backed document chat to browser-based knowledge maps and developer tools with deterministic scoring.

## How I approach a project

- Start with a specific workflow and build something people can try.
- Keep source evidence visible when an answer depends on a document or external data.
- Make model behavior, fallbacks, and limitations clear.
- Write tests and setup documentation alongside the implementation.
